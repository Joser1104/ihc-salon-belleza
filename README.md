# Proyecto: Sistema de Reservas para Salón de Belleza

## Integrantes
* José Rodrigo Quintana Coca

## Tipo de Proyecto
Aplicación Móvil / Web interactiva para gestión de citas.

## Modalidad
Individual

## Problema Inicial
La estilista no tiene un control claro de sus citas porque todo se maneja por mensajes o llamadas. Esto hace que las citas se crucen a la misma hora, la gente cancele a última hora y ella pierda tiempo tratando de coordinar con sus clientes en lugar de atenderlos.
